# landtender — ежедневный трекер земельных тендеров Израиля

Программа раз в сутки обходит государственные порталы Израиля и частную
площадку Yad2, собирает земельные лоты, считает **стоимость земли** и
**количество единиц строений**, делит выдачу по порогу в **1 000 000 $** и
присылает сводку в Telegram — только то, чего не было вчера.

```
🇮🇱 Земельные тендеры Израиля — дневная сводка
Дата: 2026-07-27
Порог: $1.00 млн · курс USD/ILS: 3.6412 (boi)
Просмотрено записей: 412 · новых: 9 · изменившихся: 3

🔥 Дороже порога — 4 лот(ов), единиц строений: 96
• חי/142/2025 · חיפה, נווה שאנן
  💰 $5.08 млн (18 500 000 ₪) · min
  🏘 единиц: 60 · 📐 4 200 м² · за единицу $84 679
  מגורים · до 2026-09-15
```

## Что считается

| Величина | Как получается |
|---|---|
| Стоимость земли | Цена сделки (`FinalPrice`) → минимальная цена (`MinPrice`) → оценка шамая (`ShumaPrice`) → цена продавца. Приоритет настраивается. |
| Стоимость в долларах | Официальный представительный курс Банка Израиля, кеш на 12 часов, откат на курс из конфига. |
| Количество единиц строений | Поле `YechidotDiur` (יחידות דיור) участка → то же поле тендера → число из текста (`12 יח"ד`) → 1 для участков под индивидуальный дом. |
| Цена за единицу / за м² | Стоимость в долларах, делённая на единицы и на площадь. |
| Группа | `premium` — от порога и выше, `standard` — ниже, `unknown` — цена неизвестна. |

Выведенные (не пришедшие напрямую) единицы помечаются знаком `≈`.
Неизвестные значения остаются пустыми — программа их не выдумывает.

## Источники

| Источник | Что даёт | Тип |
|---|---|---|
| `rmi_michrazim` — apps.land.gov.il | Земельные тендеры Управления земель Израиля (рм"י): участки, цены, единицы жилья, сроки. Основной источник. | гос. |
| `data_gov_il` — data.gov.il | Открытые наборы данных правительства (CKAN): тендеры и сделки с землёй. | гос. |
| `gov_mr` — mr.gov.il | Портал государственных закупок: тендеры с земельными ключевыми словами. Вспомогательный — цена в карточке есть не всегда. | гос. |
| `yad2` — yad2.co.il | Частные объявления о продаже участков — рыночная цена рядом с государственной. | частн. |

Новый портал добавляется одним классом: наследник `Source` в
`landtender/sources/`, регистрация в `landtender/sources/__init__.py` и
секция `[sources.имя]` в конфиге. Остальной конвейер менять не нужно.

## Установка

```bash
git clone https://github.com/vadimsheinberg-beep/usreal.git
cd usreal
pip install -e .          # или: pip install -r requirements.txt
cp landtender.example.toml landtender.toml
```

Требуется Python 3.11+ (используется stdlib-модуль `tomllib`).

## Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Узнайте `chat_id`: напишите боту и откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
3. Задайте переменные окружения:

```bash
export TELEGRAM_BOT_TOKEN="123456:AA..."
export TELEGRAM_CHAT_ID="-1001234567890"
```

Токен в конфиге не хранится: там стоит ссылка `env:TELEGRAM_BOT_TOKEN`.

## Запуск

```bash
landtender check                       # проверить доступность источников
landtender run --dry-run               # прогон без отправки: сводка в консоль
landtender run                         # ежедневный запуск
landtender run --sources rmi_michrazim # только один источник
landtender export --format csv --tier premium --days 30
landtender stats                       # состояние базы и последний запуск
```

Полезные флаги `run`: `--threshold-usd` (свой порог), `--full-refresh`
(перезабрать детали всех тендеров), `--no-notify`, `--export-csv/--export-json`.

Коды возврата: `0` — успех, `1` — упали все источники, `2` — ошибка конфигурации.

### Первый запуск

Первый прогон видит все лоты как новые, поэтому сводка будет большой, а
детали тендеров догружаются с паузой в секунду — это нормально и занимает
несколько минут. Разумно начать так:

```bash
landtender run --no-notify     # наполнить базу молча
landtender run                 # дальше приходит только новое
```

## Ежедневный запуск

### cron

```cron
0 9 * * * cd /opt/usreal && /usr/bin/env TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... \
          /opt/usreal/.venv/bin/landtender run >> /var/log/landtender.log 2>&1
```

### systemd

Файлы `deploy/landtender.service` и `deploy/landtender.timer` — скопируйте в
`/etc/systemd/system/`, затем:

```bash
systemctl enable --now landtender.timer
```

### GitHub Actions

`.github/workflows/daily.yml` запускает трекер каждый день в 06:00 UTC.
Добавьте секреты репозитория `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
База между запусками сохраняется через `actions/cache`.

## Конфигурация

Все параметры и комментарии — в `landtender.example.toml`. Наиболее важные:

```toml
[general]
threshold_usd = 1_000_000     # порог деления на группы
rate_limit_delay = 1.0        # пауза между запросами; ниже 0.5 порталы дают 429

[valuation]
price_preference = ["final", "min", "appraisal", "asking"]
include_development_costs = false   # прибавлять ли הוצאות פיתוח к цене земли

[telegram]
send_standard_tier = true     # false — присылать только лоты дороже порога
```

## Особенности источников, о которых стоит знать

* **Схемы порталов меняются без предупреждения.** Поля ищутся по спискам
  синонимов (английские ключи + ивритские подписи), поэтому переименование
  колонки обычно не ломает сбор. Если поле всё же пропало — значение будет
  пустым, а не ошибочным.
* **Числовые коды назначения и статуса** рм"י расшифровываются таблицей в
  `landtender/sources/rmi_michrazim.py`. Незнакомый код оставляет поле
  пустым; свои значения задаются через `purpose_codes` / `status_codes` в
  секции `[sources.rmi_michrazim]`.
* **Yad2 защищается от ботов.** Отказ этого источника не роняет запуск — он
  попадает в раздел «Источники с ошибкой». При необходимости в конфиг можно
  положить куки: `cookie = "env:YAD2_COOKIE"`.
* **Цены участков живут в деталях тендера**, а не в поиске. Детали
  догружаются только для новых и изменившихся тендеров (кеш отпечатков),
  лимит за запуск — `details_budget`.
